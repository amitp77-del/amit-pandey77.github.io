# Amit Pandey — Advanced Cybersecurity Portfolio

A responsive, single-page cybersecurity portfolio with a dark navy + orange visual identity.

## Included
- Executive hero section and professional summary
- Operational scale metrics
- Cybersecurity capability cards
- Illustrative defence-in-depth architecture
- Filterable project showcase
- ISO 27001:2022 GRC dashboard mock-up (clearly labelled sample data)
- Technology landscape and contact links
- Mobile navigation and responsive layout

## Publish on GitHub Pages

1. Create or open the repository `amit-pandey77/amit-pandey77` (or another repository you own).
2. Upload all files and folders from this package. Keep `index.html`, `styles.css`, `script.js`, and `assets/` at the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment and open the published URL shown in Settings → Pages.

For a project repository instead of a profile repository, the site URL will usually be `https://USERNAME.github.io/REPOSITORY/`.

## Customise before publishing
- Confirm the displayed experience, CISM credential, scale metrics and tool list.
- Replace the LinkedIn and GitHub links if needed.
- Add a professional email address only if you want it public.
- Add links to real repositories and case studies as you publish them.
- Do not add confidential government, client, network, IP-address, incident or infrastructure details.

## Important accuracy notes
- The GRC dashboard uses illustrative demo numbers; it is not an actual compliance score or audit result.
- The architecture is a generic conceptual diagram, not a production network map.
- Project cards are portfolio focus areas and concepts unless linked to a real public implementation.
- This site does not claim that GitHub Pages has been configured or that the site is already live.
