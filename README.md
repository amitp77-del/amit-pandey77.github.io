# AK Portfolio — akportfolio.online

Personal cybersecurity portfolio for Amit Pandey.

## GitHub Pages

1. Create/use the repository `amit-pandey77.github.io`.
2. Upload the contents of this folder to the repository root.
3. Ensure `CNAME` contains `akportfolio.online`.
4. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
5. Configure DNS at your domain registrar:
   - `@` → GitHub Pages apex records shown by GitHub
   - `www` → CNAME to `amit-pandey77.github.io`
6. In GitHub Pages, enable **Enforce HTTPS** after DNS becomes active.

## Before publishing

- Replace `assets/img/profile.jpg` with your professional photo if desired.
- Replace `assets/docs/Amit-Pandey-CV.pdf` with your current CV.
- Update the LinkedIn URL in `index.html`.
- Update `contact@akportfolio.online` if you want another email address.

The design is an original cybersecurity-themed implementation inspired by the reference site's modern portfolio presentation; it does not copy the reference site's personal content.
